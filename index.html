Bruxism Detection Device — Edge AI Medical Device

SYS: BRUXISM-EDGE-AI
PROBLEM

Bruxism (teeth grinding) often goes undetected until it causes dental or jaw damage, and effective monitoring requires continuous, real-time tracking throughout the night — a cloud-dependent approach adds latency and requires a stable internet connection, making it unreliable for consistent, always-on monitoring during sleep.

WHAT WE DID

Built a wearable-style medical device that detects bruxism episodes in real time and triggers an automated response mechanism to help manage the condition — running entirely on-device with no cloud dependency, using a custom-trained machine learning model for local classification.

TECHNICAL DETAILS
  • Used an ESP32 as the processing platform with a gyroscope-based motion sensor to capture jaw movement data
  • Collected and labelled motion data to train a custom classification model for detecting grinding episodes
  • Deployed a Random Forest machine-learning model directly on the microcontroller for real-time, on-device classification
  • Built the full embedded data pipeline: capturing, processing, and feeding sensor data to the on-device model
  • Implemented an automated response mechanism triggered upon detection
  • Focused on edge inference to enable standalone, always-on overnight operation, with fast response time regardless of internet connectivity

Pet Tracker — GNSS & Wireless Location Device

SYS: PET-TRACK-GNSS
PROBLEM

Pet owners often struggle to track their pets' location reliably in both outdoor and indoor environments — GPS alone loses accuracy indoors, and many trackers have short battery life or lack easy remote monitoring, making them impractical for everyday use.

WHAT WE DID

Built a low-power pet-tracking device offering up to 7 days of battery life on a single charge, combining GPS-based outdoor positioning with Wi-Fi based indoor positioning, with app-based control and cloud connectivity for remote monitoring.

TECHNICAL DETAILS
  • Used an EFR32 microcontroller running Zephyr RTOS for modular, reliable firmware
  • Integrated Wi-Fi connectivity alongside GNSS-based satellite positioning to support both indoor and outdoor location tracking
  • Tuned antenna configuration to maintain strong location accuracy across both indoor and outdoor conditions
  • Implemented low-power design techniques to achieve up to 7 days of battery life on a single charge
  • Integrated cloud connectivity for remote data sync and monitoring, with a companion app for user control
  • Structured the firmware so GNSS, Wi-Fi, and core system logic run as independent, maintainable modules

Autonomous Wheelchair Control System

SYS: WHEELCHAIR-CTRL
PROBLEM

People with mobility impairments who rely on wheelchairs need both manual control for everyday flexibility and autonomous navigation for reduced physical strain — but combining the two reliably, while also ensuring the chair stops safely before hitting obstacles, is a real-time control challenge.

WHAT WE DID

Built the embedded control system for a smart wheelchair supporting two operating modes — manual joystick control and autonomous navigation — with automatic mode switching, real-time obstacle detection, and a hard-stop safety mechanism to prevent collisions.

TECHNICAL DETAILS
  • Designed an ESP32-based RTOS firmware architecture, splitting control, navigation, sensing, and communication into separate real-time tasks for reliability and responsiveness
  • Implemented automatic detection and switching between manual and autonomous operating modes based on system state
  • Delivered a responsive joystick-to-motor command pipeline with real-time processing for manual mode
  • Processed and executed autonomous navigation commands to drive motor control in autonomous mode
  • Implemented 1D LiDAR-based close-range obstacle detection with a hard-stop algorithm to immediately halt the chair when an obstacle is detected within a critical distance
  • Built a PID-based speed control loop for smooth, accurate motor control, used across both modes

6-DOF Robotic Arm with Integrated 12-DOF Servo Gripper

SYS: ARM-GRIPPER-6DOF
PROBLEM

Automated handling and manipulation tasks need a robotic arm that can move precisely through multiple axes while also gripping objects of different shapes and sizes reliably — most low-cost gripper solutions lack the fine coordination needed for consistent, damage-free grasping.

WHAT WE DID

Built a complete 6-degree-of-freedom robotic arm system with an integrated 12-DOF servo-driven gripper, giving it both flexible multi-axis reach and precise, repeatable grasping across multiple object shapes — controlled in real time over CAN bus with a live dashboard for monitoring and control.

TECHNICAL DETAILS
  • Developed ESP32-based firmware with CAN bus communication for real-time control of the arm's 6 joints
  • Implemented position-based control loops for accurate, repeatable arm movement, with real-time feedback handling
  • Developed dedicated embedded firmware for a 12-DOF gripper mechanism, generating synchronized multi-channel signals for coordinated joint actuation
  • Implemented precise positioning and timing coordination across all 12 gripper joints, tightly synchronized with arm motion over the shared control bus
  • Tested and validated reliable grasping across multiple object shapes
  • Built a dashboard interface for real-time control and monitoring of the full arm + gripper system

Landing Assistance System — Private Aircraft

SYS: LIDAR-LANDING-AST
PROBLEM

Small private aircraft often lack affordable, reliable systems for real-time ground-proximity awareness during landing — pilots need accurate, low-latency distance data to make safe landing decisions, especially in conditions where visual judgment alone isn't enough.

WHAT WE DID

Built a landing-assistance system for small private planes that provides real-time ground-proximity data during landing, using LiDAR-based sensing with calibrated, filtered readings processed on a dedicated onboard computing platform.

TECHNICAL DETAILS
  • Used a 1D LiDAR sensor for real-time ground distance data capture, with an ESP32 handling Wi-Fi connectivity
  • Performed sensor filtering and calibration to ensure accurate, reliable distance readings under real flight conditions
  • Ran higher-level ground-proximity processing and decision logic on an Orange Pi
  • Built an end-to-end data pipeline from sensor capture to processed output, to support safer, more informed landing decisions in a real aircraft environment
